পুরনো Google Sheet থেকে ডাটা আনা

একবারই করতে হবে। শুধু Super Admin।

⭐ সবচেয়ে সহজ: পুরো Google Sheet একবারে আনা (.xlsx)

যেসব অ্যাপ এখন "Apps Script ইঞ্জিনে" চলে (Attendance, Chemical Order, Report ও পরের অ্যাপগুলো), সেগুলোর পুরনো সব ডাটা Google Sheet-এই থাকে।
১) পুরনো অ্যাপের Google Sheet খুলুন → File → Download → Microsoft Excel (.xlsx)।
২) নিচে অ্যাপ বেছে ফাইলটা দিন → ইমপোর্ট। শিটের প্রতিটা ট্যাব হুবহু নতুন অ্যাপে আসবে (আগের একই নামের ট্যাব বদলে যাবে)।
৩) অ্যাপের নিজের JSON ব্যাকআপ থাকলে সেটা অ্যাপের ভেতরের Backup/Restore দিয়েও আনা যায়।
পিন, SMS key-এর মতো গোপন সেটিং শিটে থাকে না — অ্যাপের Admin থেকে আবার দিতে হবে।

📦 অ্যাপের নিজের JSON ব্যাকআপ থেকে আনা (সবচেয়ে নিরাপদ)

পুরনো Apps Script অ্যাপ থেকে যে JSON ব্যাকআপ ডাউনলোড হয়, নতুন অ্যাপের একই জায়গায় Restore দিলে সব ডাটা হুবহু চলে আসে। কোনো ডাটা হারায় না।
🧪 Chemical Order: পুরনো অ্যাপে Admin → Backup & Restore → Lifetime ব্যাকআপ ডাউনলোড → নতুন অ্যাপে একই জায়গায় Restore from JSON।
📊 Monthly Report: পুরনো অ্যাপের Admin → Backup থেকে সম্পূর্ণ ব্যাকআপ (JSON) → নতুন অ্যাপে একই জায়গায় Restore।
🕘 Employee Attendance: পুরনো অ্যাপে Admin → Backup → লাইফটাইম এক্সপোর্ট → নতুন অ্যাপে Admin → Backup → Restore (Full replace)। তারপর অ্যাপটা একবার খুললেই Report-এ মাসিক সামারি চলে যায়।
🌴 Leave Application: পুরনো অ্যাপে Admin → Backup → Lifetime → নতুন অ্যাপে Admin → Backup → Restore (Replace)।
পিন অ্যাপের ভেতরে থাকে না: সব অ্যাপের অ্যাডমিন পিন Admin Console → Apps & admin PINs থেকে।
